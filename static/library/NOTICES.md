# Bundled music

The original MIDI files and pre-ingested performance data in this directory are
separate musical data distributed alongside the GPL-3.0 application.

Both editions are marked **Public Domain** by the Mutopia Project. Its licensing
page says the contributor dedicated their contribution to the public domain.
The catalogue records the edition page, download URL, contributor, declared source,
review date and SHA-256 for each unmodified MIDI. No recording is bundled.

- Chopin, Prelude Op. 28 No. 7: Edition Peters, typesetting by Magnus Lewis-Smith.
  https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=470
- Bach, Prelude BWV 846: typesetting by Tobias Erbsland; underlying edition is
  listed as unknown by the source, retained as unknown here.
  https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=5

Licence evidence: https://www.mutopiaproject.org/legal.html#publicdomain
Reviewed 2026-10-16. Source labels are recorded as published. The JSON files are
lossless inspections from score_import.py with provenance added, not recovered
printed notation or new musical arrangements.
